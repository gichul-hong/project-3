프로젝트 진행 및 평가에 관하여 공지드립니다.

[개요]
본 프로젝트는 주어진 데이터셋의 객체(subject)를 유지한 채 새로운 이미지를 생성하는 것(Subject-driven customization)을 목표로 합니다.

[데이터셋]
CustomConcept101 Dataset을 활용하며 평가 대상 서브젝트는 그 중 10개입니다. 두 파일을 drive에 올려두었습니다.
dataset.zip — 서브젝트별 레퍼런스 이미지
prompt.zip — 서브젝트별 테스트 프롬프트 10개
두 zip의 폴더/파일 이름은 서브젝트명으로 1:1 대응됩니다.

[평가]
1. 정량 평가 (30%)
서브젝트별로 프롬프트 10개에 대해 이미지 10장을 생성하고 두 점수를 구합니다.
CLIP-I(Image-to-Image): 객체가 유지되었는가
CLIP-T(Text-to-Image): 프롬프트를 따랐는가
2. 정성 평가 (30%)
너무 획일적인 것보다 다양한 이미지가 생성되었는가
레퍼런스를 그대로 옮겨온 정도가 심한가 심하지 않은가
3. 아이디어 (40%)
학습한 논문 외에 새로운 아이디어나 방법론을 시도해보았는가
단순한 학습량 증가나 하이퍼파라미터 튜닝 이상의 기여가 있는가
기존 기법을 창의적으로 응용하거나 변형하여 실험에 반영했는가
평가 코드 - 평가에는 evaluation.py를 활용하시기 바랍니다. 서브젝트 하나씩 실행하며, CLIP-T와 CLIP-I 두 숫자가 출력됩니다.
생성 이미지의 파일명 정렬 순서가 프롬프트 줄 순서와 같아야 합니다 (e.g. 0.png … 9.png). i번째 이미지가 i번째 프롬프트로 채점되므로 순서가 어긋나면 점수가 떨어지니 주의해 주세요.

[제출 사항]

(1) 생성 이미지 (.zip)
서브젝트별 생성 이미지 10장, 총 10 × 10 = 100장
파일명은 프롬프트 순서에 맞게 0.png … 9.png
(2) 발표 자료
CLIP Score: CLIP-I, CLIP-T를 각각 서브젝트별 평균 + 전체 평균 → 총 (10 + 1) × 2 = 22
생성 이미지는 일부만 첨부 (전체 첨부 불필요)
코드 별도 제출 없음
실습 코드에서 활용한 영역과 본인 아이디어가 반영된 영역을 나눠서 발표할 것
서브젝트별/이미지별로 적용 방법론이 다를 경우 (1) 통일했을 때의 점수, (2) 개별 적용했을 때의 점수를 나눠 기재 (예: 프롬프트, Inversion 방법론 등)
[기타]
생성하실 때는 프롬프트를 일부 수정하여 사용하셔도 됩니다. Textual Inversion이나 DreamBooth 등에서 쓰는 베이스라인 프롬프트가 방법마다 다를 수 있기 때문입니다. 다만 변경한 경우 그 내용을 발표자료에 명시해 주세요. 또한 평가 시에는 기존 evaluation.py에 명시된 프롬프트를 그대로 사용해야 합니다.
이미지 생성 시 베이스 모델은 실습 때 진행한 것과 동일한 stable-diffusion-3.5-medium(https://huggingface.co/stabilityai/stable-diffusion-3.5-medium)을 사용해야 합니다.
